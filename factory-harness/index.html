Qué es Project Factory

Un sistema multi-agente que convierte un brief de producto en código listo para producción, sin intervención humana.

🤖

9 Agentes Especializados

Cada agente tiene un rol claro: product manager, arquitecto, planner, diseñador UX/UI, developer, code reviewer, QA, verifier y un supervisor que vigila todo el pipeline.

🔄

Pipeline Autónomo

El código fluye por 10 fases con gates de validación en cada transición. Si algo falla, el sistema rechaza y reapunta automáticamente a la fase correcta.

🛡️

Gates a Nivel de SO

Cada transición pasa por un gate que valida el output de la fase anterior. Seguridad de nivel sistema operativo para garantizar calidad.
