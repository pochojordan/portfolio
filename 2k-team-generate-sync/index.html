Cómo funciona

Tres pasos entre el chat y el partido.

01

Crea la sala

Se genera un ID corto y un link de invitación para compartir con el grupo.

02

Monta el roster

Cada jugador entra, se identifica y aparece en la lista compartida al instante.

03

Sortea el quinteto

Un click elige cinco nombres al azar. Reinicia y repite hasta que salga el equipo.
